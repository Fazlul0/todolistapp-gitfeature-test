# Todo App

A simple single-file todo app. Open `index.html` in a browser to use it.

## Features

- Add, complete, and delete todos
- Undo a delete (or "Clear completed") from the toast for 5 seconds
- Double-click a todo to edit it
- Filter by All, Active, or Completed
- See how many items are left and clear completed ones
- Todos are saved in your browser's localStorage
